# Music Store Analysis - SQL Project

## Overview
This project showcases how SQL was used to analyze a music store's sales data to derive actionable insights. The analysis focused on identifying top-performing artists, popular music genres, and revenue trends to support business decisions.

## Key Insights
- **Top Artists & Genres:** Determined the most profitable artists and popular genres.
- **Sales Trends:** Identified seasonal sales patterns and peak revenue months.
- **Revenue Growth:** Provided actionable recommendations for targeted marketing and promotions.

## Tools Used
- **SQL (MySQL, PostgreSQL)** for data extraction and analysis
- **Data Cleaning** to ensure accurate analysis
- **Reporting** for insights presentation

## Outcome
- Delivered actionable recommendations that contributed to a **10% increase** in targeted sales.
- Improved marketing strategies by focusing on high-demand genres and artists.
- Supported data-driven decision-making for future product launches.
